# 🍽️ Union Bank Canteen Management System

A full-stack canteen management system built with **Java, Spring Boot, MySQL, JWT authentication, REST APIs, HTML, CSS and JavaScript**.

The system supports meal ordering, user authentication, order management, role-based access control and administrative analytics.

## 🚀 Features

### User Features
- Secure user authentication with JWT
- Meal browsing and ordering
- Order history
- Favorites management
- Profile management
- Real-time order tracking
- Feedback and meal ratings

### Admin Features
- Dashboard analytics
- Order management
- Menu management
- User management
- Sales and activity reports
- Role-based access control

## 🛠️ Technology Stack

### Backend
- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- MySQL
- JWT
- Maven

### Frontend
- HTML5
- CSS3
- JavaScript (ES6+)
